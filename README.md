# InCarnation

Application web statique inspirée de [mesJumeaux](https://github.com/samszo/mesJumeaux) pour explorer les personnes nées le même jour que d'autres sont mortes.

## Fonctionnalités

- recherche par jour/mois ;
- interrogation directe de Wikidata via SPARQL ;
- visualisation des correspondances sous forme de graphe ;
- affichage des photos, noms et dates de naissance / mort.

## Lancer le projet

```bash
npm install
npm start
```

Puis ouvrir http://localhost:4173 dans le navigateur.

## Tests

```bash
npm test
```
